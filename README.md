# homebrew-ghr

Homebrew tap for [ghr](https://github.com/cataggar/ghr) — an installer for GitHub releases.

## Install

```sh
brew install cataggar/ghr/ghr
```

Or tap first:

```sh
brew tap cataggar/ghr
brew install ghr
```

> Note: the `ghr` name in `homebrew-core` refers to a different project (tcnksm/ghr). Use the fully-qualified `cataggar/ghr/ghr` to disambiguate.

## Uninstall

```sh
brew uninstall ghr
brew untap cataggar/ghr
```
